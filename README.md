# Mac Auto Power Servo

Arduino + サーボモーターを使って、MacBookの電源ボタンを物理的に押すプロジェクト

## 概要

Macをサーバとして使用する際、電源が切れた後に自動起動できない問題を解決するため、Arduinoとサーボモーターを使って物理的に電源ボタンを押す仕組みを構築します。

## 目的

- 1日に1回、指定時刻に自動でMacBookの電源をONにする
- 停電や予期せぬシャットダウン後の自動復旧を可能にする

## 必要な部品

| 部品名 | 型番/仕様 | 数量 |
|--------|-----------|------|
| マイコンボード | Arduino Uno | 1 |
| サーボモーター | SG90 | 1 |
| ジャンパーワイヤー | オス-メス | 3本 |
| USBケーブル | Type-B (Arduino給電用) | 1 |

## 配線図

### SG90サーボモーターの接続

```
Arduino Uno          SG90サーボモーター
├─ 5V     ─────────  VCC (赤)
├─ GND    ─────────  GND (茶/黒)
└─ Pin 9  ─────────  Signal (オレンジ/黄)
```

### ピン配置の詳細

Arduino Unoのデジタルピン9付近は以下のように配置されています：

```
[GND] [GND] [5V] [5V] ...
 ...  [8]   [9]  [10] ...
```

デジタルピン9の近くに5VとGNDがあるため、配線がシンプルになります。

## 使い方

### 1. テスト動作（現在のステップ）

サーボモーターが正常に動作するか確認します。

```bash
# Arduino IDEで servo_test/servo_test.ino を開く
# ボードとポートを選択
# アップロード
```

シリアルモニタ（9600 baud）を開くと、1秒ごとにサーボの動作状況が表示されます。

### 2. 本番実装（今後）

- RTC（リアルタイムクロック）モジュールを追加
- 指定時刻に1回だけサーボを動かすプログラムに変更
- MacBookの電源ボタンに物理的な押下機構を設置

## 動作原理

1. Arduinoが指定時刻を検知
2. サーボモーターが動作し、電源ボタンを押す
3. 数秒後にサーボが元の位置に戻る
4. Macが起動

## トラブルシューティング

### サーボが動かない

- 配線を確認してください（特にGND接続）
- 5V電源が供給されているか確認
- サーボモーターの初期不良の可能性

### サーボが震える

- 電源容量不足の可能性があります
- USB給電ではなく、外部電源の使用を検討してください
